# Ronak Chovatiya portfolio

A responsive, accessible, buildless portfolio for GitHub Pages. Plain HTML, CSS, and JavaScript; no client secrets, tracking, paid API, or build dependency. Typography loads from Google Fonts with local fallbacks.

## Preview

Run `python3 -m http.server 4173` from this directory and open `http://localhost:4173`.

## Publish

Use the public repository `rchovatiya88/rchovatiya88.github.io`. Copy this directory's contents to the root of its `main` branch. In Settings → Pages choose Deploy from a branch, then `main` and `/(root)`. Keep `.nojekyll` so GitHub serves the static files directly. See [GitHub Pages quickstart](https://docs.github.com/en/pages/quickstart).

## Content

Edit `index.html` for work history and project descriptions, `styles.css` for styling, and `script.js` for project filtering and email-copy feedback. Replace `assets/Ronak_Chovatiya_Resume_2026.pdf` when updating the downloadable resume. Test both desktop and mobile sizes after changes.

The project artwork is a visual illustration built with CSS, not a screenshot or a claim about live product metrics. The engineering loop and AGENTS.md card illustrate working practices. Public portfolio includes professional email and region; it omits phone and street address.
